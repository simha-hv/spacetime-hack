Eight renderers, one identical scene. Same four fighters, same choreography, same HUD — the only thing that changes is how it is drawn. Each runs a ~20 second loop with knockdowns and a winner, so you can judge motion, not just a still. Arrow keys flip between them.

Clay

Soft-lit vinyl toy. Matte materials, warm studio key, big soft shadows. The closest of the eight to Party Animals.

three.js · ~160KB gz

Toon

Cel shaded with black inverted-hull outlines and a hard 3-step ramp. Bold and graphic; the most legible at TV distance.

three.js · ~160KB gz

Noir

One hard spotlight in a black room. Fight-night staging: silhouettes, long cast shadows, a flash of emissive on every hit.

three.js · ~160KB gz

Pixel Diorama

Orthographic 3D rendered at a fifth resolution and upscaled hard. Boxy voxel bodies, chunky shadows, snapped 8-way facing.

three.js · ~160KB gz · runs on anything

Arcade

WebGL 2D with true additive bloom and a spark system. Glow actually bleeds across shapes rather than faking it with shadows.

pixi.js v8 · ~110KB gz

Sketchbook

Hand-drawn ink on paper, redrawn on a 12fps clock so the lines “boil” like traditional animation. Nothing else looks like it.

rough.js · ~10KB gz · 0 WebGL

Isometric

2.5D with a warm painted palette, gradient bodies and soft contact shadows. Character without a 3D engine at all.

canvas 2d · 0 deps · ~11KB

Neon

Top-down arcade. Glowing rim, motion trails, impact rings. Reads instantly and never occludes anyone, but the least characterful.

canvas 2d · 0 deps · ~9KB
